# Smart Calculator in C

A beginner-friendly menu-driven calculator built using C programming.

## Features
- Addition, Subtraction
- Multiplication, Division
- Modulus
- Power Calculation
- Square Root
- Percentage Calculation
- Division by Zero Handling
- Continuous Calculations

## Technologies
- C Programming
- GCC Compiler
- Math Library

## Concepts Used
- Variables and Data Types
- Functions
- Loops
- Switch Case
- Conditional Statements
- Mathematical Operations

## How to Run

Compile:
gcc main.c -o calculator.exe -lm
Run:
.\calculator.exe
